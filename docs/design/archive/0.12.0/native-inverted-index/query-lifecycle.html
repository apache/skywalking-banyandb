Partly open

Query IR and execution

Queries operate on immutable segment-local document sets, apply snapshot deletions, and then merge results across pinned segments.

Required query nodes

Query :=
    All | None | LiveUniverse
  | Term(field, termBytes)
  | ByteRange(field, lower?, upper?, includeLower, includeUpper)
  | NumericRange(field, lower?, upper?, includeLower, includeUpper)
  | TimeRange(lower?, upper?, includeLower, includeUpper)
  | Prefix(field, prefixBytes)
  | Wildcard(field, patternBytes)
  | Match(field, text, analyzerOverride?, operator: AND|OR)
  | Boolean(must[], should[], mustNot[], minShould)
  | SeriesConstraint(seriesIDs[])
  | AndTime(query, timeRange)

Execution paths

Node Dictionary operation Posting algebra Bound
Term Single FST lookup. One posting minus deletions. Constant dictionary lookup.
Range Ordered dictionary enumeration between encoded bounds. Union term postings. Term expansion limit required.
Prefix FST seek and prefix-constrained enumeration. Union term postings. Expansion and cancellation required.
Wildcard Bounded automaton/FST enumeration. Union term postings. Pattern and expansion limits required.
Boolean AND Execute cheapest/selective children first where known. Intersection. Context checked between operations.
Boolean OR Execute all required children. Union; enforce min-should semantics. Context checked between operations.
NOT Evaluate child under explicit live universe. Universe AND NOT child. No implicit match-all dependency.
QUERY-001 MUST

Apply the snapshot deletion mask to every segment result before exposing a hit.

QUERY-002 MUST

Represent pure negative queries using an explicit live universe. MatchField may not silently stand in for field existence.

QUERY-003 MUST

Preserve independent inclusive/exclusive lower and upper range endpoints and unbounded sides.

QUERY-004 MUST

Check context cancellation during dictionary expansion, postings combination, cross-segment merge, stored projection, and sorting.

QUERY-005 SHOULD

Reuse immutable postings and pooled iterators without allowing pooled state to escape a query lifetime.

?

Pure-negative and field-universe behavior becomes authoritative only when DEC-003 approves the intentional legacy defect fixes.

SORT-001 MUST

Load doc values only for requested sort fields and candidate documents, and compare encoded bytes using the same term codec used by the writer.

SORT-002 MUST

Pin one immutable snapshot for the complete page operation; offset-based repeated searches against changing generations are prohibited.

SORT-003 SHOULD

Use search-after keys containing every sort component, deterministic tie key, and pinned generation rather than growing offset scans.

PROJ-001 MUST

Return all repeated stored values through the raw visitation API. Scalar convenience APIs must document their selection rule.

PROJ-002 MUST

Keep internal-field hiding policy in the product adapter, not in the ICE stored-field reader.

?

Section 20 must approve missing-value placement, repeated-value selection, identity ordering, and the stable tie key before the native collector becomes authoritative.

Surface open

Durability, publication, and recovery

The snapshot is the commit record. Final file names become visible only after complete bytes are synced and validated.

Write segment temp

Unique same-filesystem name; truncate/create exclusively.

Sync and validate

fsync, close, reopen or validate complete bytes.

Rename segment

Atomic rename to final .seg; fsync parent directory.

Write snapshot temp

Complete v3 manifest referencing valid final segments.

Commit snapshot

fsync, rename to .snp, fsync parent directory.

Callback and GC

Acknowledge durability; later collect unreachable files.

DUR-001 MUST

Use same-filesystem temp-write, file sync, close, validate, atomic rename, and parent-directory sync for segments and snapshots.

DUR-002 MUST

Complete a supported persistent callback exactly once after its snapshot rename and directory sync succeed, or exactly once with terminal failure during close.

DUR-003 MUST

On startup, enumerate snapshots newest-first and select the newest generation whose records, referenced segments, codecs, and structural invariants all validate. The reserved CRC32 field is not a selection criterion.

DUR-004 MUST

Never rewrite or migrate production bytes merely because an index is opened.

DUR-005 MUST

Preserve bluge.pid exclusive writer-lock behavior during the compatibility window; read-only opens must not acquire it.

?

DEC-006 selects which batch entry points expose durable callbacks. The ordering and exactly-once terminal completion rules apply to every entry point that is approved.

Recovery classification

Artifact Recovery action Visibility
Unrenamed temp file Ignore; remove after lock ownership and age validation. Never committed.
Final segment not referenced by selected snapshot Classify as orphan; defer GC until retained-generation scan completes. Not live.
Newest invalid snapshot Report and try next older generation. Never selected.
Snapshot references missing/invalid segment Reject entire snapshot generation. Never partially selected.
No usable snapshot with snapshot files present Writable open fails; admin verifier reports all causes. No fabricated empty index.
13
Stable design

Stream live content; publish replacement before ref-safe GC.

Merge, deletion, expiry, and GC

Deletes remain snapshot overlays until merge omits them from a replacement segment.

MERGE-001 MUST

Merge only documents live in the pinned source snapshot plus product-specific private drop decisions.

MERGE-002 MUST

Rebuild postings, doc values, stored values, identity, timestamps, analyzers, and repeated fields without lossy document reconstruction.

MERGE-003 MUST

Property expiry evaluation must read bounded stored fields through SegmentView and add drops to a cloned bitmap.

MERGE-004 MUST

Publish the replacement segment and snapshot before making source files eligible for collection.

GC-001 MUST

Delete a segment or snapshot only when no retained manifest and no active reader/backup reference requires it.

GC-002 SHOULD

Retry platform-specific unlink failures with bounded backoff and expose pending-GC bytes and oldest age.

i

Merge policy—when and which segments to merge—is tunable. Merge correctness, deletion ownership, and publication order are not.

14
Fixture gate

Raw migration remains mandatory and must become self-validating.

External segments, admin, and backup

A raw segment is accepted only after full validation and becomes live only through the single-writer snapshot path.

External receive state machine

Stage

Write bounded chunks to an OS/same-filesystem temp file.

Verify transfer

Length, expected hash, retry identity, and completion.

Validate ICE

Version, offsets, FST, Roaring, compression, and limits; retain but do not validate CRC32.

Deduplicate

Optional identity reconciliation under mutation serialization.

Publish file

Sync, validate, rename, and directory sync.

Introduce

Commit a later snapshot containing the segment.

EXT-001 MUST

Validate expected type/version, length, hash, every address, embedded codec, and configured limit before final publication. Preserve but do not validate the reserved CRC32 field.

EXT-002 MUST

Make retry and idempotency explicit; a repeated transfer may not introduce duplicate logical content accidentally.

EXT-003 MUST

Serialize deduplication and introduction with concurrent identity updates and preserve all surviving representations.

ADMIN-001 MUST

Provide OpenReadOnly, Count, LatestGeneration, WalkDocuments, Verify, Rebuild, stored/doc-value visitation, and stable search-after without legacy APIs.

BACKUP-001 MUST

Pin one committed snapshot and copy or hard-link exactly its manifest and referenced segments; exclude locks, temps, failed parts, and unreferenced files.
