Limit values open

Classes of limits are normative; numeric budgets require measurement.

Integrity, malformed input, and resource limits

Every untrusted count, address, codec payload, expansion, and decompression result is checked before use.

Limit class Enforcement point Required failure Value
File and segment bytes Before mmap/read allocation and external receive. Typed limit error. benchmark
Fields and field-name bytes Footer/field-index validation. Reject segment. benchmark
Terms, term length, analyzed expansion Batch admission and FST enumeration. Reject batch/query. benchmark
Stored/doc-value decompressed bytes Before decompression destination growth. Reject chunk. corpus
Compression ratio Chunk decompression. Reject suspected bomb. corpus
Roaring cardinality and bytes Before bitmap load. Reject payload. ≤ segment docs plus byte budget.
Wildcard/range term expansion During FST enumeration. Cancel or typed expansion error. workload
Top N and projection bytes Before collector/result allocation. Reject request. API policy
Snapshot segment count Before record allocation. Reject snapshot. workload
SAFE-001 MUST

Malformed bytes must return descriptive typed errors without panic, hang, integer-wrap slicing, unbounded allocation, or partial publication.

SAFE-002 MUST

Use checked addition/multiplication for all offset, width, count, and allocation arithmetic.

SAFE-003 MUST

Verify Roaring document numbers are below segment numDocs and snapshot deletions are within their referenced segment.

SAFE-004 MUST

Never log raw Property source, arbitrary indexed binary values, or complete terms by default when reporting corruption.

16
Hard gate

Compatibility is behavioral and bidirectional, not byte identity.

Compatibility contract

Native output may use different valid Roaring containers or omit optional optimizations, but both readers must observe identical live documents and required query results.

Producer/action Consumer Required proof Gate
Historical/legacy directory Native read-only Fields, terms, postings, stored values, doc values, timestamps, manifests, deletions. reader
Legacy directory + native append/update/delete Legacy and native Open, query, merge, restart, and identical live documents. writer
Native ICE v3 segment Legacy reader Dictionary, posting, stored, doc-value, query, merge, and restart parity. writer
Native snapshot v3 Legacy reader Exact segment set, metadata, deletion masks, reserved CRC32 field placement, and recovery. manifest
Legacy/native raw segment Legacy/native receiver Validate, receive, dedup on/off, retry, crash, and later introduction. external
Native pre-crash filesystem Native recovery Select last complete commit and safely classify orphans. crash
COMPAT-001 MUST

Preserve same-file old-binary rollback for the maintainer-approved compatibility window.

COMPAT-002 MUST

Define the historical release floor from real BanyanDB directories, not from nominal snapshot version support.

COMPAT-003 MUST

Record fixture producer commit, Go/OS/architecture, compressor, codec versions, options, SHA-256, and canonical logical results.

COMPAT-004 MAY

Emit bytes different from the legacy writer when multiple valid encodings exist, provided every cross-reader and logical parity test passes.

17
Required program

No production writer without corpus, fuzz, crash, and cross-read evidence.

Verification and test program

Tests establish the contract independently of the legacy source and remain executable after dependency removal.

Golden corpus boundaries

Area Mandatory fixtures
Stored chunks 0, 1, 127, 128, and 129 documents; empty, repeated, binary, long, and multi-field stored values.
Doc values 1023, 1024, and 1025 documents; missing, repeated, 0xff, backslash, empty, numeric, and timestamp terms.
Postings One-hit/general; sparse/dense/run Roaring; detail absent/present; adaptive chunks; all/none cardinality.
Integer widths Every uvarint width transition, large offsets, max legal counts, and overflowing encodings.
Analysis Every analyzer, Unicode edge, numeric extrema, inclusive range boundary, wildcard escape, and MATCH operator.
Lifecycle Pre/post update, delete, merge, expiry, external receive, dedup, restart, snapshot v1-v3, and orphan files.
Corruption One-at-a-time mutation of every offset, count, length, FST value, bitmap, compressed chunk, and version. CRC32-field mutation is intentionally accepted because the field is not validated.
